# SQL لمحلل البيانات

## 1) ما هي SQL؟
SQL هي لغة الاستعلام القياسية للتعامل مع قواعد البيانات العلائقية.

## 2) لماذا هي مهمة في Data Analysis؟
- استخراج البيانات المطلوبة مباشرة من قواعد البيانات
- فلترة وتجميع البيانات قبل التحليل
- بناء استعلامات دقيقة وقابلة للتكرار

## 3) ماذا يحتاج المتعلم أن يعرف؟
- أساسيات SELECT وWHERE وORDER BY
- JOIN بأنواعه الأساسية
- GROUP BY والدوال التجميعية
- Subqueries وCTE بمستوى أساسي

## 4) التسلسل التعلمي المقترح
1. أساسيات SQL والاستعلامات البسيطة
2. الفلترة والترتيب
3. الربط بين الجداول (JOIN)
4. التجميع والتحليل
