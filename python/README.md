# Python لمحلل البيانات

## 1) ما هي Python؟
Python لغة برمجة مرنة وسهلة نسبيًا، وتُستخدم كثيرًا في تحليل البيانات والأتمتة.

## 2) لماذا هي مهمة في Data Analysis؟
- تنفيذ تحليلات أعمق من الأدوات التقليدية
- أتمتة المهام المتكررة
- استخدام مكتبات قوية مثل Pandas وNumPy وMatplotlib

## 3) ماذا يحتاج المتعلم أن يعرف؟
- أساسيات اللغة (المتغيرات، الحلقات، الدوال)
- التعامل مع الملفات والبيانات
- مقدمة في Pandas
- أساسيات التصور البياني

## 4) التسلسل التعلمي المقترح
1. أساسيات Python
2. معالجة البيانات بالجداول
