# 📊 مصادر تحليل البيانات بالعربي

## عن المستودع
هذا المستودع يجمع مصادر عربية مختارة لتعلّم تحليل البيانات بطريقة مرتبة وسهلة التصفح.

## لمن هذا المستودع؟
- لمن يبدأ تعلّم تحليل البيانات
- لمن يفضّل المصادر العربية
- لمن يريد معرفة ما يتعلّم بعد Excel أو SQL أو Power BI
- لمن يبحث عن مسار منظم بدل التشتت بين مصادر متفرقة

## ماذا يفعل محلل البيانات؟
محلل البيانات يجمع البيانات وينظفها ويحللها ويعرضها بصريًا، ثم يشرح النتائج بشكل يساعد على اتخاذ قرارات أفضل.
