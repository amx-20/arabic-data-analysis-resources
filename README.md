# 📊 مصادر تحليل البيانات باللغة العربية

<a id="about"></a>
## عن المشروع
هذا المستودع هو دليل عربي مبسّط لتعلّم **Data Analysis** بشكل منظّم.  
الفكرة هي جمع موارد عربية مفيدة في مكان واحد، بحيث يسهل عليك معرفة ماذا تتعلّم أولًا وماذا يأتي بعده، بدل البحث العشوائي.

التركيز في الإصدار الأول على 5 مسارات أساسية:
- Excel
- SQL
- Power BI
- Python
- Statistics

<a id="who-is-this-for"></a>
## لمن هذا المستودع؟
- لأي شخص يريد بدء تعلّم Data Analysis
- للمبتدئين الذين يفضّلون الشرح العربي
- لمن يعرف أداة واحدة (مثل Excel) ويريد معرفة الخطوة التالية
- لمن يريد خطة واضحة بدل التنقّل بين مصادر متفرقة

<a id="what-does-a-data-analyst-do"></a>
## ماذا يفعل محلل البيانات (Data Analyst)؟
محلل البيانات يحوّل البيانات الخام إلى معلومات تساعد على اتخاذ القرار.  
عادةً يشمل عمله:
- جمع البيانات
- تنظيفها وتنظيمها
- تحليلها لاستخراج الأنماط
- عرض النتائج عبر تقارير ورسوم
- توصيل الاستنتاجات بشكل واضح لأصحاب القرار

## الأدوات والمهارات

<a id="excel"></a>
### Excel
مهم جدًا في بداية الطريق لتنظيف البيانات، الحسابات السريعة، والتحليل الأولي.  
➡️ الموارد التفصيلية: [excel/README.md](./excel/README.md)

<a id="sql"></a>
### SQL
الأداة الأساسية للتعامل مع قواعد البيانات واستخراج البيانات المطلوبة للتحليل.  
➡️ الموارد التفصيلية: [sql/README.md](./sql/README.md)

<a id="power-bi"></a>
### Power BI
يستخدم لبناء لوحات معلومات وتقارير تفاعلية لعرض النتائج بشكل احترافي.  
➡️ الموارد التفصيلية: [power-bi/README.md](./power-bi/README.md)

<a id="python"></a>
### Python
مفيد للتحليل المتقدم، الأتمتة، ومعالجة البيانات باستخدام مكتبات مثل Pandas.  
➡️ الموارد التفصيلية: [python/README.md](./python/README.md)

<a id="statistics"></a>
### Statistics
الأساس لفهم البيانات بشكل صحيح واتخاذ قرارات مبنية على نتائج موثوقة.  
➡️ الموارد التفصيلية: [statistics/README.md](./statistics/README.md)
