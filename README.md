# 📊 مصادر تحليل البيانات بالعربي

## عن المستودع

المستودع ده بيجمع مصادر عربية مختارة تساعدك تتعلم **تحليل البيانات (Data Analysis)** بشكل منظم وبسيط، وبيسهّل عليك تلاقي مصادر عربي كويسة بدل ما تضيّع وقت في البحث ومش عارف تبدأ منين.

مناسب ليك لو عايز تبدأ من الصفر، بتفضّل تتعلم بالعربي، مش عارف الخطوة اللي بعد كده، أو عايز مصادر مرتبة في مكان واحد بدل ما تفضل تحفظ عشرات اللينكات.

## محلل البيانات بيعمل إيه؟

> محلل البيانات بيجمع البيانات، وينضفها، ويفسرها، عشان يجاوب على سؤال معين أو يحل مشكلة معينة.

### الست خطوات لتحليل البيانات:

- **Business Question:** تحديد المشكلة اللي عايز تحلها.
- **Get Data:** جمع البيانات اللي محتاجها للتحليل.
- **Explore Data:** استكشاف البيانات بصريًا عشان تفهم إيه اللي موجود فيها.
- **Prepare Data:** تنظيف البيانات، وعمل الحقول المحسوبة، والتأكد من صحة البيانات.
- **Analyze Data:** استخدام تقنيات تحليل البيانات عشان تفهمها وتفسرها وتوصل لاستنتاجات بناءً على المطلوب.
- **Present Findings:** عرض النتائج والاستنتاجات لأصحاب المصلحة.
