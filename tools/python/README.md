# Python لمحلل البيانات

## 1) ما هي Python؟
Python لغة برمجة سهلة وقوية تُستخدم كثيرًا في تحليل البيانات، الأتمتة، وبناء الحلول التحليلية.

## 2) لماذا هي مهمة في Data Analysis؟
- ممتازة للتعامل مع بيانات كبيرة
- تنفيذ التحليل المتقدم بسرعة
- أتمتة المهام المتكررة
- مطلوبة جدًا في سوق العمل

## 3) ماذا يحتاج المتعلم أن يعرف؟
- أساسيات اللغة (متغيرات، حلقات، دوال)
- مكتبة Pandas لتنظيف وتحليل البيانات
- Matplotlib/Seaborn للتصور
- Jupyter Notebook

## 4) التسلسل التعلمي المقترح
1. أساسيات Python
2. Pandas وقراءة الملفات
3. تنظيف البيانات وتحليلها
4. التصور البياني
5. Mini Projects
