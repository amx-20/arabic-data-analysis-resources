# SQL لمحلل البيانات

## 1) ما هي SQL؟
SQL (Structured Query Language) هي اللغة المستخدمة للتعامل مع قواعد البيانات: استخراج البيانات، تصفيتها، وتجميعها.

## 2) لماذا هي مهمة في Data Analysis؟
- أغلب بيانات الشركات مخزنة في قواعد بيانات
- ضرورية لاستخراج البيانات قبل تحليلها
- بتسهل فهم العلاقات بين الجداول

## 3) ماذا يحتاج المتعلم أن يعرف؟
- SELECT, WHERE, ORDER BY
- GROUP BY و Aggregations
- JOINs
- Subqueries و CTEs بمستوى أساسي
