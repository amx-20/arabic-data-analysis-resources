<h2 align="right">SQL</h2>

<p dir="rtl" align="right">
<strong>SQL</strong> هي لغة بتستخدم للتعامل مع قواعد البيانات، وبتساعدك تخزن البيانات وتسترجعها وتنظمها وتديرها.
</p>

<p dir="rtl" align="right">
ومعرفتك بـ SQL مهمة جدًا لمحلل البيانات، لأنها بتخليك تقدر تستخرج البيانات اللي محتاجها، وتفلترها، وتربط بين جداول مختلفة، وتحللها بشكل أسرع وأكثر كفاءة.
</p>
