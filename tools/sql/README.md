<h2 align="right">SQL</h2>

<p dir="rtl" align="right">
<strong>SQL</strong> من الأدوات الأساسية لمحلل البيانات، لأنها بتساعدك تتعامل مع قواعد البيانات وتستخرج البيانات اللي محتاجها.
</p>

<p dir="rtl" align="right">
من خلال SQL، تقدر تسترجع البيانات وتفلترها وتربط بين الجداول وتحلل البيانات بشكل أسرع وأكثر كفاءة.
</p>
