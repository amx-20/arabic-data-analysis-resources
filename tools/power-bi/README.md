# Power BI لمحلل البيانات

## 1) ما هو Power BI؟
Power BI أداة Business Intelligence لبناء لوحات معلومات وتقارير تفاعلية.

## 2) لماذا هو مهم في Data Analysis؟
- تحويل نتائج التحليل إلى Story واضحة
- عرض البيانات بصريًا بطريقة تساعد على القرار
- مشاركة التقارير مع الفريق أو الإدارة بسهولة

## 3) ماذا يحتاج المتعلم أن يعرف؟
- استيراد البيانات وربط المصادر
- تنظيف البيانات بشكل أساسي
- بناء Visuals ولوحات Dashboard
- أساسيات DAX بمستوى تمهيدي

## 4) التسلسل التعلمي المقترح
1. التعرف على الواجهة والمرئيات الأساسية
2. استيراد البيانات وتنظيمها
3. بناء تقارير ولوحات معلومات
4. مقدمة في DAX
