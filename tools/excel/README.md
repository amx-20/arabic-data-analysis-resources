# Excel لمحلل البيانات

## 1) ما هو Excel؟
Excel أداة جداول بيانات تُستخدم لتنظيم البيانات، إجراء الحسابات، وبناء تقارير أولية بسرعة.

## 2) لماذا هو مهم في Data Analysis؟
- بداية عملية وسهلة للتعامل مع البيانات
- ممتاز في التنظيف السريع والتحليل الوصفي
- مستخدم بشكل واسع في بيئات العمل

## 3) ماذا يحتاج المتعلم أن يعرف؟
- الصيغ الأساسية والدوال (مثل IF و VLOOKUP/XLOOKUP)
- Pivot Tables
- تنظيف البيانات (فرز، تصفية، إزالة التكرار)
- الرسوم البيانية الأساسية

## 4) التسلسل التعلمي المقترح
1. أساسيات واجهة Excel والصيغ
2. التعامل مع الجداول والتنظيف
3. Pivot Tables وCharts
4. تطبيقات تحليل بيانات صغيرة
