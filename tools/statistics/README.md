# الإحصاء لمحلل البيانات

## 1) ما هو الإحصاء؟
الإحصاء هو العلم الذي يساعدنا على فهم البيانات وتفسيرها بشكل صحيح بدل الاعتماد على الانطباعات.

## 2) لماذا هو مهم في Data Analysis؟
- بيدي معنى للنتائج
- يساعد على تفسير الاتجاهات
- ضروري لفهم الارتباط، التوزيع، والاحتمالات

## 3) ماذا يحتاج المتعلم أن يعرف؟
- المتوسط، الوسيط، والانحراف المعياري
- التوزيعات الإحصائية الأساسية
- الارتباط والانحدار بمستوى تمهيدي
- أساسيات الاحتمالات

## 4) التسلسل التعلمي المقترح
1. الإحصاء الوصفي
2. الاحتمالات الأساسية
3. التوزيعات
4. الارتباط والانحدار البسيط
